# Hershey Font Data Notice

`hershey-fonts.json` contains selected vector glyph data derived from the `hersheytext` 2.0.0 data file. The `hersheytext` project states that its JSON font data is public domain. The font data may be used for any purpose, provided this acknowledgement is retained:

- The Hershey Fonts were originally created by Dr. A. V. Hershey while working at the U.S. National Bureau of Standards.
- The format of the font data was originally created by James Hurt, Cognition, Inc., 900 Technology Park Drive, Billerica, MA 01821.
- The SVG font conversion was prepared by Windell H. Oskay.

The CommBurn text-to-stroke converter is original project code. The `hersheytext` renderer and its runtime dependencies are not used by CommBurn.
